## 3. Link rules (checked against Google docs via WebSearch, 2026-10-26)
Verified (Google spam policies, Search Central): "links with optimized anchor text in articles, guest posts, or press releases distributed on other sites" are listed as link spam. The 2017 blog on large-scale article campaigns lists keyword-rich links, the same or similar content across many sites, and duplicated site content as risk factors. Links that are paid or promotional should carry rel=nofollow or rel=sponsored. Descriptive anchor text is normal for ordinary editorial links.
Not verified: whether each free site auto-applies nofollow, and how Google weights any single wire link. Treat all as nofollow-equivalent. Do not rely on them for ranking.
Rules:
- Anchors are only the brand name ("Infinitum Corporation"), the bare URL (https://www.theinfinitumcorporation.com), or "website / Telegram / Discord / X". Never anchor `cybersecurity consulting` or any other keyword.
- Rotate which destinations get links per day: website (every release), plus one or two of X https://x.com/infinitumceo, Telegram https://t.me/infinitumcorporation, Discord https://discord.gg/QVT7dWHUQa. Telegram is included in release 1 per Marketing.
- Link to the website homepage or one real page. No UTM-stuffed or redirect links, and no links to unrelated sites.
- Never pay for links or buy upgrades (Boost, KIN, Starter). Don't add reciprocal backlink tricks (e.g. SubmitPR's "verify a backlink" upsell) unless William approves.

## 5. Anti-duplicate rule
- Each day's body must be materially new: new topic, new headline, new quote, new opening paragraph, new examples. At most the boilerplate and contact block repeat.
- Before posting, compare the draft against all earlier drafts (see daily-log.md). If shared sentences exceed about 20% of the body, rewrite it.
- Never re-post or resubmit the same text to the same or another site. Never submit a timed-out form again before checking the inbox and the site (as with RedPress).
- Record the exact title and URL of every release in published.md.
