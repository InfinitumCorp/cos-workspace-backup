Attackers are using AI. Defenders can too. But AI only helps a security team if you set the rules first.

Today I'm sharing my first Infinitum Corporation whitepaper: "AI for Security Operations: Practical, Integrated Steps for Mid-Size Organizations."

I read security through one lens: irregular warfare. Indirect. Non-attributable. Asymmetric. That is how U.S. joint doctrine describes it. It is also how a modern intrusion campaign behaves.

Don't take my word for it. Look at the numbers:

- Verizon's 2026 DBIR: exploiting vulnerabilities is now the top way into a breach, at 31%, up from 20%.
- IBM's 2026 Cost of a Data Breach Report: organizations using security AI and automation extensively averaged USD 4.00 million per breach, versus USD 5.93 million for those using none. Key word: averaged. An association, not a guarantee.

Let that sink in.

My advice is simple and not glamorous. Govern first. Measure a baseline. Pilot with analysts in the loop. Point AI at exposure. Secure the AI itself. Widen automation only as the evidence earns it.
